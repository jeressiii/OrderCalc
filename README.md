# Калькулятор заказа — версия 1.0

Небольшое веб-приложение для расчета стоимости покупки: одна цена за единицу,
количество одинаковых товаров, процент скидки и способ доставки. Работает
локально в браузере без установки, сервера и интернета.

Команда «Крутые перцы»: Молдаванский Р.Д., Белов А.М..
Учебное заведение: РТУ МИРЭА. Группа: ИКБО-43-24.
Дисциплина «Тестирование и верификация программного обеспечения», 2026.

Подробные требования приведены в [техническом задании](TZ_OrderCalc_v1.0.docx).
Это учебная версия с семью преднамеренными дефектами.

## Что нужно для работы

- Компьютер с Windows 10 или 11; основная среда проверки — Windows 11.
- Microsoft Edge или Google Chrome с включенным JavaScript.
- Установка программ, права администратора и подключение к интернету не нужны.
- Другие операционные системы и браузеры требуют отдельной проверки.

## Запуск

1. Распакуйте архив в отдельную папку. В Windows щелкните по архиву правой
   кнопкой мыши и выберите «Извлечь всё…».
2. Откройте папку `calculator` и дважды щелкните `index.html`.
3. Если файл открылся в редакторе, используйте «Открыть с помощью» и выберите
   Edge или Chrome. Также можно перетащить файл в окно браузера.

Вверху страницы должно появиться название «Калькулятор заказа». Все четыре
файла `index.html`, `style.css`, `app.js` и `export.js` должны находиться вместе
в папке `calculator`. Для завершения работы закройте вкладку браузера.

## Работа с калькулятором

### Ввод параметров

Заполните поля слева:

- **Цена за единицу:** от 0,01 до 100 000,00 ₽ включительно, не более двух
  цифр после точки или запятой. Допустимы, например, `100`, `100,5`, `100.50`.
  Записи `1e3`, `-10`, `,5` и `100.` недопустимы.
- **Количество:** целое число от 1 до 100 включительно.
- **Скидка:** целый процент от 0 до 50 включительно.
- **Доставка:** «Самовывоз» или «Курьер».

Пробелы по краям числовых значений игнорируются. Начальные значения:
пустая цена, количество 1, скидка 0, самовывоз.

### Расчет

Нажмите «Рассчитать» или Enter в поле ввода. При корректных данных справа
появятся стоимость товаров, сумма скидки, стоимость после скидки, доставка
и выделенный итог. При ширине окна 375 пикселей расчет находится под формой.

Нормативные формулы:

1. Стоимость товаров = цена × количество.
2. Сумма скидки = стоимость товаров × процент / 100. Сумма скидки округляется
   один раз до копеек: половина копейки округляется вверх.
3. После скидки = стоимость товаров − сумма скидки.
4. Самовывоз бесплатный. Курьер стоит 300,00 ₽, но становится бесплатным
   при стоимости после скидки от 3 000,00 ₽ включительно.
5. Итого = стоимость после скидки + доставка.

Пример без скидки: цена 100,00 ₽, количество 2, самовывоз — итог 200,00 ₽.
Все денежные значения показываются с двумя знаками после запятой и знаком ₽.

### Ошибки ввода и изменение параметров

При невалидном вводе появляется русское сообщение об ошибке, введенные данные
сохраняются, расчет не показывается. Первой проверяется цена, затем количество,
затем скидка. Исправьте ввод и нажмите «Рассчитать» повторно.

Изменение любого поля или способа доставки скрывает прежний результат
и отключает скачивание до нового расчета.

### Сброс

Кнопка «Сбросить» должна возвращать начальные значения, убирать сообщение
об ошибке и результат, отключать скачивание. В учебной версии результат
ошибочно остается видимым после сброса (BUG-006); поля возвращаются
к начальным значениям, скачивание отключается.

### Экспорт

После расчета нажмите «Скачать расчет». Браузер скачает `order.txt` в кодировке
UTF-8. В файле должны быть цена, количество, процент скидки, способ доставки
и все пять денежных строк последнего действующего расчета.

До расчета, после изменения параметров и после сброса кнопка недоступна.
Кнопка скачивания сама по себе расчет не выполняет. В учебной версии строка
«Итого» экспортируется с ошибкой BUG-007, подробно описанной в отчете.

## Где хранятся данные

Параметры и результат существуют только в открытой странице. При перезагрузке
или повторном открытии возвращается начальное состояние. Истории, базы данных,
localStorage и отправки данных в сеть нет. Для сохранения текстового результата
предусмотрен только экспорт с указанным учебным ограничением.

## Как сообщить об ошибке

Укажите версию приложения, операционную систему, браузер и его версию,
введенные значения, выбранную доставку, шаги, ожидаемый и фактический результат.
Приложите снимок экрана, а при ошибке скачивания — полученный `order.txt`.
Известные семь дефектов уже перечислены в отчете.
